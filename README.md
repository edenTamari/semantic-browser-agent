# Semantic Browser Agent
Built a browser-only automation workflow in Python using Playwright.
Integrated a local LLM (Qwen via Ollama) for semantic content analysis and navigation decisions.
Inspected both visible page content and hidden DOM elements to discover relevant information.
Implemented semantic link classification to prioritize relevant navigation paths dynamically.
Detected and interacted with contextual UI actions to reveal dynamically loaded content.
Implemented search-box discovery and browser-driven search as an additional retrieval strategy.
